# Course Information System

This project is a Python program that uses dictionaries to store and look up course information by course number, instructor, or time block.

## What the Program Does
This program allows the user to search for course information in different ways:
- by course number
- by instructor
- by time block

For each course, the program can display:
- room number
- instructor
- meeting time

## Features
- Uses three separate dictionaries
- Looks up course details quickly
- Includes a friendly error message if a course is not found
- Allows partial instructor name searches
- Allows time block searches, such as the 9:00 AM hour

## File Included
- `dictionaries.py` – main Python program

## How to Run the Program
1. Open the Python file in Visual Studio Code or another IDE.
2. Run the program.
3. Choose one of the menu options.
4. Enter the course number, instructor name, or time block when prompted.

## Notes
The original assignment focused on searching by course number. I added the instructor and time block search options to make the program more practical and easier to use.
