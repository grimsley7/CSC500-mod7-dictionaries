# Course Information System

This project is a Python course information system that uses multiple dictionaries to store and retrieve course data.

## Features
- Search by course number
- Search by instructor
- Search by time block
- Displays room number, instructor, and meeting time
- Includes error handling for invalid searches

## Files
- `course_information_system.py` – main Python program

## How to Run
1. Open the Python file in Visual Studio Code or another IDE.
2. Run the program.
3. Choose a menu option:
   - Search by course number
   - Search by instructor
   - Search by time block
   - Quit
